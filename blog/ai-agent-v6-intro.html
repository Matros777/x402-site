💰 ИИ-Агент v6: Автономный Крипто-Трейдер, Который Работает Пока Вы Спите

2026-07-23 · 3 мин чтения

В мире криптовалют, где рынок работает 24/7, а цены BTC и ETH меняются за секунды, трейдеры сталкиваются с дилеммой: либо пропустить сделку из-за сна, либо рисковать эмоциями. ИИ-Агент v6 решает это — он никогда не спит, не подвержен стрессу и использует стратегии, отточенные на 20 годах данных.

Почему это революция?

Крипто-рынок волатилен. Ручная торговля требует постоянного мониторинга. ИИ-Агент работает автономно через MCP-сервер — мост между агентом и биржей Pionex.

Что даёт MCP:

  • Чтение свечей (OHLCV), RSI, EMA, объёмов.
  • Сканирование рынка каждые 5–15 минут.
  • Автоматическое создание грид-ботов.
  • Управление стоп-лоссами и тейк-профитами.

Как работает агент: три режима

Режим 1: Автономный Крон

Агент сканирует рынок по расписанию. При нахождении сигнала (дивергенция RSI + объём + EMA) он создаёт бота без вашего участия.

Режим 2: Ручной Чат

Вы даёте команду «Сканируй BTC». Агент показывает сигнал, но бот создаёт только после вашего подтверждения.

Режим 3: Режим Скрипт — Агент Пишет Код Сам

Это самый мощный режим. Вы даёте агенту задачу: «Найди стратегию для BTC, протестируй её на истории и создай скрипт для сканирования».

Как это работает:

  1. Агент выбирает стратегию. Вы описываете, что хотите: например, «стратегия на основе дивергенции RSI и объёма». Агент ищет в своей базе знаний подходящий подход.
  2. Агент пишет скрипт. Он создаёт код на Python, который будет сканировать рынок через MCP-сервер и выполнять стратегию.
  3. Проверка через другого агента. Сгенерированный код отправляется на проверку более умному агенту (например, ChatGPT-5 или Claude). Тот анализирует логику, находит ошибки и указывает на них.
  4. Исправление. Ошибки возвращаются первому агенту, и он исправляет код. Цикл повторяется, пока скрипт не станет идеальным.
  5. Запуск в крон. Готовый скрипт добавляется в расписание и начинает работать автономно.

#!/usr/bin/env python3
# btc_eth_scanner_mcp.py
# Автономный сканер BTC/ETH через MCP-сервер
import asyncio
import json
import os
from datetime import datetime
from mcp import MCPClient
# --- Настройки ---
SYMBOLS = ["BTC/USDT", "ETH/USDT"]
INTERVAL = "15m"
LIMIT = 100
MIN_VOLUME_RATIO = 1.5
CONFIDENCE_THRESHOLD = 0.95
async def get_candles(client, symbol):
    """Получает свечи через MCP"""
    result = await client.call("market.get_candles", {
        "symbol": symbol,
        "interval": INTERVAL,
        "limit": LIMIT
    })
    return result.get("candles", [])
def calculate_rsi(candles, period=14):
    """Расчёт RSI"""
    closes = [c["close"] for c in candles]
    if len(closes) < period + 1:
        return None
    gains = []
    losses = []
    for i in range(1, len(closes)):
        diff = closes[i] - closes[i-1]
        gains.append(diff if diff > 0 else 0)
        losses.append(-diff if diff < 0 else 0)
    avg_gain = sum(gains[-period:]) / period
    avg_loss = sum(losses[-period:]) / period
    if avg_loss == 0:
        return 100
    rs = avg_gain / avg_loss
    return 100 - (100 / (1 + rs))
def calculate_ema(candles, period):
    """Расчёт EMA"""
    closes = [c["close"] for c in candles]
    if len(closes) < period:
        return None
    multiplier = 2 / (period + 1)
    ema = closes[0]
    for price in closes[1:]:
        ema = (price - ema) * multiplier + ema
    return ema
def check_divergence(candles, rsi):
    """Проверка дивергенции RSI"""
    if len(candles) < 10 or rsi is None:
        return None
    price = candles[-1]["close"]
    prev_price = candles[-5]["close"]
    rsi_now = rsi[-1]
    rsi_prev = rsi[-5]
    # Бычья дивергенция: цена ниже, RSI выше
    if price < prev_price and rsi_now > rsi_prev:
        return "bullish"
    # Медвежья дивергенция: цена выше, RSI ниже
    if price > prev_price and rsi_now < rsi_prev:
        return "bearish"
    return None
async def scan_symbol(client, symbol):
    """Сканирует одну пару"""
    candles = await get_candles(client, symbol)
    if not candles:
        return None
    closes = [c["close"] for c in candles]
    rsi = calculate_rsi(candles)
    ema20 = calculate_ema(candles, 20)
    ema50 = calculate_ema(candles, 50)
    volume_ratio = candles[-1]["volume"] / sum(c["volume"] for c in candles[-20:]) * 20
    divergence = check_divergence(candles, [calculate_rsi(candles[:i+1]) for i in range(len(candles))])
    if divergence and volume_ratio > MIN_VOLUME_RATIO:
        if divergence == "bullish" and ema20 > ema50:
            return {"symbol": symbol, "signal": "LONG", "confidence": 0.96}
        if divergence == "bearish" and ema20 < ema50:
            return {"symbol": symbol, "signal": "SHORT", "confidence": 0.96}
    return None
