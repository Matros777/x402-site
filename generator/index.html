Настройка и генерация x402 агента

1. Логика агента

Можно вставить любой рабочий код. Функция — agent_logic(data: dict) -> dict. Импорты пиши над функцией. Доп. pip-пакеты — в раскрывающемся блоке под кнопкой генерации.

2. Платёжные настройки

EVM-адрес в сети Base. Именно на него будут приходить платежи от агентов.

По умолчанию: facilitator.xpay.sh (оплата работает сразу). CDP нужен только если хочешь попасть в каталог agentic.market — для этого потребуется официальный API-ключ Coinbase Developer Platform. Без успешного settle через CDP листинга не будет.

Ключи берутся из env при деплое (CDP_API_KEY_ID, CDP_API_KEY_SECRET). Создать: portal.cdp.coinbase.com. В коде ниже можно оставить плейсхолдеры.

Для agentic.market: Bazaar extension + CDP + один реальный settle после деплоя. Verify alone недостаточно — индексируется только после settle.

3. Эндпоинт
4. Листинг (опционально)

Что проверяет Bazaar (и что будет в конфиге):

  • URL well-formed + HTTPS
  • Endpoint reachable, returns HTTP 402 Payment Required
  • Valid JSON response, Resource object present
  • x402 version is 2
  • Accepts array: scheme=exact, network supported, USDC asset
  • Price ≥ $0.001 USDC, payTo address present, maxTimeoutSeconds set
  • Bazaar extension present + info block + output metadata + example + schema

После деплоя проверь листинг: agentic.market

Полный HTTPS-URL эндпоинта. Именно его увидят агенты в Bazaar.

Скопируй промпт ниже и отправь ChatGPT / Claude / Cursor — модель напишет agent_logic в формате, который понимает этот генератор. Импорты — над функцией. Ответ — только dict.

ЖЁСТКИЕ ПРАВИЛА: 1) Верни ОДИН фрагмент Python-кода — без markdown-ограждений, без пояснений вокруг. 2) Обязательна функция: def agent_logic(data: dict) -> dict 3) Вход: только dict (поля из JSON body и/или query). Используй data.get("key", default). 4) Выход: только dict (JSON-сериализуемый: str, int, float, bool, list, dict). Никаких Response, print, файлов на диск. 5) Нужные библиотеки: import ПИШИ НАД def agent_logic. Стандартная библиотека и уже есть в сервере: os, json, httpx. Остальное пользователь укажет в «доп. библиотеки». 6) Не ставь веб-сервер, FastAPI, x402, verify/settle — это генерирует сайт сам. 7) Ошибки обрабатывай внутри и возвращай dict с полем "error", не бросай наружу необработанные исключения без нужды. 8) Сеть: если ходишь в API — httpx или requests, timeout обязателен. 9) Не хардкодь секреты; бери из os.getenv("NAME", ""). Доп. библиотеки (pip)

Если вам нужны доп. библиотеки — вставляйте их сюда (через запятую или с новой строки). Они попадут в requirements.txt при генерации. Импорты всё равно пишите в коде над agent_logic.

Пакеты (pip) — в requirements.txt. Python-импорты (from datetime import datetime, import json) — вставятся в код автоматически. Стандартная библиотека в requirements не попадает.
