Проверка сгенерированного агента

Проверь 402-ответ, разбери PAYMENT-REQUIRED и получи готовую команду оплаты под твой пример запроса.

1. Данные для проверки

Браузер не видит заголовки чужих серверов (CORS), поэтому запрос идёт через прокси proxy.cors.sh — он отдаёт и заголовок, и тело.

Реальная оплата не выполняется. Проверяется только корректность 402 и заголовка.

    Инструкция для кода, который выдал генератор. Код запускаем локально, наружу открываем через Cloudflare Tunnel и проверяем здесь — без реальной оплаты.
    

        
    1. Запусти код локально
    
        
    Сохрани код из генератора как agent.py, рядом положи requirements.txt, затем:
    
        
    pip install -r requirements.txt

# run the server (in the folder with the code)
python3 agent.py

# or via uvicorn:
uvicorn app:app --host 0.0.0.0 --port 8000
    

        
    2. Установи Cloudflare Tunnel
    
        
    Любой из способов (выбери под свою ОС):
    
        
    # macOS (Homebrew)
brew install cloudflared

# Linux (deb) — Debian/Ubuntu
sudo apt install cloudflared

# Windows (winget)
winget install cloudflare.cloudflared

# or any OS via npm
npm install -g cloudflared
    

        
    3. Открой туннель к твоему агенту
    
        
    В отдельном терминале (пока сервер работает):
    
        
    cloudflared tunnel --url http://localhost:8000
    
        
    Вывод покажет ссылку вида https://random-words.trycloudflare.com — это публичный адрес твоего агента. Оставь терминал открытым.
    

        
    4. Заполни форму на этой странице
    
        
    URL агента — ссылка из туннеля (для демо-агентов генератора — https://ваш-домен.onrender.com). Метод и тело — как в примере генератора.
    

        
    5. Вставь код и нажми «Подставить поля из кода»
    
        
    Скопируй в поле «Сгенерированный код» свою agent_logic (или весь app.py) из генератора и нажми кнопку. Она сама найдёт все data.get("поле", "дефолт") и подставит их в «Пример тела запроса (JSON)».
    

        
    6. Нажми «Проверить x402»
    
        
    Инструмент отправит запрос, проверит статус 402, заголовок PAYMENT-REQUIRED и его структуру, а внизу покажет готовые команды оплаты (awal) и проверки (curl).
